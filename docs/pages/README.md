# Mo RPG Hero browser demo

A small, dependency-free auto-battle game built specifically for static hosting. It provides combat waves, class roles, party recruitment, level progression, equipment drops, codex pages, and localStorage save persistence.

Open `index.html` through a static HTTP server rather than `file://` when testing. The demo's data and saves are independent from the Electron and Android runtime.

See [GitHub Pages deployment](../GITHUB_PAGES.md) for deployment setup.
