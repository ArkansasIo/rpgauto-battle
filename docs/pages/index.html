Frontier codex

A browser prototype of the RPG data model. The standalone demo keeps its own state and is intentionally separate from desktop and Android save files.

🛡

Classes & roles

Guardian soaks damage. Ranger deals reliable ranged damage. Cleric heals wounded allies. Mage strikes all enemies.

🌲

World zones

Thornwatch Frontier (1–10), Goldenroad (8–18), Dunesea (18–30), Frostmarch (28–42), Blackfen (38–52), Emberfall (48–62), Tempest Isles (58–72), Aether Crown (68–82), Voidscar (80–100).

⚔

Combat pipeline

Auto-target → role ability → damage mitigation → defeat/reward → wave spawn. The same steps are reflected in the visible combat log.

✦

Loot rarities

Common Rare Epic Legendary. This prototype uses a compact item pool.
